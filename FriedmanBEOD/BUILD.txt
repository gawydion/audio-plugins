Brown Eye OD — BE-100 style overdrive
=====================================

JUCE 8 plugin. Exports Audio Unit (GarageBand / Logic) and VST3
(Reaper, Ableton, Cubase, etc.). GarageBand does not load VST.

Needs: macOS, Xcode (App Store), CMake 3.22+, Git.

1. Install CMake if needed:
     brew install cmake

2. In Terminal, from this folder:

     cmake -B build -G Xcode
     cmake --build build --config Release

   First run downloads JUCE 8 and takes several minutes.

3. After a successful build, plugins are copied to:
     ~/Library/Audio/Plug-Ins/Components/Brown Eye OD.component
     ~/Library/Audio/Plug-Ins/VST3/Brown Eye OD.vst3

4. GarageBand
     Settings → Audio/MIDI → enable Audio Units
     Smart Controls → plugin slot → Audio Units → Grok Audio → Brown Eye OD

5. If GarageBand does not see it:
     auval -v aufx BeOD GrkA
     Then reboot GarageBand. On newer macOS you may need to
     codesign the .component (Apple Developer ID) for it to load.

Knobs (same layout as the original pedal)
  GAIN      — drive through the stacked op-amp stages
  VOLUME    — output level
  TIGHT     — high-pass before the gain stack (150 Hz → 3.3 kHz)
  BASS      — low shelf around 80 Hz
  TREBLE    — high cut after the hard clipper
  PRESENCE  — low-pass 1.3 kHz → 7.2 kHz into the hard clip
  TRIM      — internal 4th-stage gain (the pot inside the real pedal)

GarageBand Smart Controls
  The blue guitar-track panel is Apple's skin (a couple of mapped knobs
  + track EQ + sends). A third-party Audio Unit cannot replace that layout.
  All seven knobs are in the real editor: wrench next to Controls / EQ.
  Track automation lists:
    Gain, Volume, Tight, Bass, Treble, Presence, Trim

Put this first on a guitar track, into a clean or edge-of-breakup amp sim.
It is a mono circuit (stereo is summed). 9–18 V headroom is not modelled;
the trim knob covers the same job.
