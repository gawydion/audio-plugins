Russian Big Muff — Sovtek Green Russian
=======================================

JUCE 8 plugin. Exports Audio Unit (GarageBand / Logic) and VST3
(Reaper, Ableton, Cubase, etc.). GarageBand does not load VST.

Needs: macOS, Xcode (App Store), CMake 3.22+, Git.

1. Install CMake if needed:
     brew install cmake

2. In Terminal, from this folder:

     cmake -B build -G Xcode
     cmake --build build --config Release

   First run downloads JUCE 8 and takes several minutes.

3. After a successful build, plugins are copied to:
     ~/Library/Audio/Plug-Ins/Components/Russian Big Muff.component
     ~/Library/Audio/Plug-Ins/VST3/Russian Big Muff.vst3

4. GarageBand
     Settings → Audio/MIDI → enable Audio Units
     Smart Controls → plugin slot → Audio Units → Grok Audio → Russian Big Muff

5. If GarageBand does not see it:
     auval -v aufx RuBM GrkA
     Then reboot GarageBand. On newer macOS you may need to
     codesign the .component (Apple Developer ID) for it to load.

Knobs
  SUSTAIN  — drive into the two silicon clip stages
  TONE     — classic muff stack (bass ← noon scoop → treble)
  VOL      — output level
  INPUT    — guitar / pickup level (roll this back like a guitar volume)

Circuit (Green Russian / V7C)
  Four NPN stages (KT3102E / 2N5088 / BC549C)
  Silicon diodes (KD521 / 1N914)
  390 Ω emitters (less gain than a NYC Muff)
  47 nF clip coupling (fat, smooth bottom)
  470 pF feedback caps
  Tone stack 20 k + 3.9 nF  ||  22 k + 10 nF

GarageBand Smart Controls
  The blue guitar-track panel is Apple's skin (not remappable by a
  third-party AU). All four knobs are in the real editor: wrench next
  to Controls / EQ. Track automation lists:
    Sustain, Tone, Volume, Input

Put this first on a guitar track, into a clean or slightly dirty amp sim.
It is a mono circuit (stereo is summed).

DSP rule: write in C what can be written in C. See ../C_CORE.txt.
The process loop lives in Source/rbm_core.c. JUCE is the AU/VST3 shell.
